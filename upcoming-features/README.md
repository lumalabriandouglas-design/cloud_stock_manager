# Upcoming features (ideas only)

Nothing in this folder is built yet. It is a parking lot so we do not forget, and so we do not mix shop work with half-done extras.

When we are ready to build one item, move it out of here into a real task.

| Idea | What it is | Where it belongs |
|---|---|---|
| [Debt](debt.md) | Someone owes the shop, or the shop owes someone | Cloud Stock Manager |
| [Loss](loss.md) | Spoiled, stolen, given away stock | Cloud Stock Manager |
| [Phone app](phone-app.md) | Same shop on a phone app, not only the website | Same shop, same login |
| [Connect to planner](connect-planner.md) | Link this shop to the personal spend / planning app | Optional, never mix books by default |

## Rules

- Shop money and personal money stay separate unless the owner taps **Connect**.
- Website and phone app must use the **same account and the same stock**. Type it once.
- Do not start debt, loss, or a second database until the live shop is calm.
